## Authentication Methods

- [[decentralized-identifiers|Decentralized Identifiers (DIDs)]] - a new identifier type enabling verifiable, decentralized digital identity
- [[didcomm|DIDComm]] - a secure, private communication protocol built on Decentralized Identifiers
- [[jwt|JWT]] - compact token format for stateless authentication
- [[session|Session]] - server-side mechanism for maintaining user state across requests
