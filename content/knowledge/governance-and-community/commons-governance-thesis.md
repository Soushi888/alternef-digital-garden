## The thesis

The current economic system extracts value from communities and concentrates it. Commons-based organizations (Open Value Networks, worker co-ops, mutual aid networks) need governance and resource-tracking tools that serve them, not corporations. But "serving them" is not just a license question: the infrastructure itself must be sovereign, meaning the community controls the rules, the data, and the fork option.

This extends the [[valueflows]] economic vocabulary from the "what" to the "where" it runs on.

## Why not just use SaaS

A commons running on a corporate SaaS platform is renting its nervous system from a counterparty that can change the price, the terms, or deplatform them. The license being open-source does not fix this if the hosting and governance are centralized. Sovereign infrastructure means the community can run, fork, and govern the coordination layer without asking a platform's permission.

## The sovereign stack

- **Substrate**: agent-centric P2P architecture (Holochain) for the data layer
- **Ontology**: ValueFlows for the economic vocabulary
- **Governance**: [[nondominium]] for the decision-making and resource-tracking layer
- **Exchange**: community exchange coordination (Requests and Offers) for the needs-and-contribution matching layer
- **Reference org**: [[sensorica]] as the living Open Value Network proving it works

## The NDO conceptual atom

Nondominium's Layer 0 is the NDO (Nondominium Object), the minimal conceptual unit from which governance, resources, and contributions compose. The strategy: ship Layer 0 first (with thorough testing and a basic UI), then layer in hREA, full UI, and the ERP bridge. Build the atom before the molecule.
